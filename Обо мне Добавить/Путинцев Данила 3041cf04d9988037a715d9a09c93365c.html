Email AI Ассистент

📊 Краткая сводка

Полностью автоматизированная система, которая отслеживает письма в Gmail, анализирует их через OpenAI, категоризирует по типам (Work, Personal, Sales, Support, Spam), определяет приоритет и создает структурированные записи в Notion. Система включает уведомления в Slack/Telegram для критичных писем, сохранение вложений в Google Drive и условные автоответы. Стоит ~$20-30/месяц и экономит часы времени на обработку входящей корреспонденции.

🎯 Суть проекта

Email to Notion Automation — реализованная система автоматической обработки входящих электронных писем и их организации в Notion через Zapier и OpenAI.

Разработал комплексную автоматизацию, которая:

  • Отслеживает новые письма в Gmail с помощью Zapier триггера
  • Анализирует содержание письма через OpenAI API (GPT-3.5-turbo или GPT-4) для интеллектуального определения параметров
  • Автоматически категоризирует письма (Work, Personal, Sales, Support, Spam, Other)
  • Определяет приоритет (High, Medium, Low) на основе содержания и отправителя
  • Генерирует краткие резюме письма для быстрого обзора
  • Проверяет требуется ли действие/ответ на письмо
  • Создает структурированные записи в Notion базе данных с полной информацией

🏗️ Архитектура и компоненты

Проект использует трёхуровневую архитектуру автоматизации через Zapier:

  1. Триггер — отслеживает новые письма в Gmail с фильтрацией по ярлыкам и исключением noreply адресов и спама
  1. Первый экшн — отправляет текст письма в OpenAI для анализа с детальным промптом, определяющим категорию, приоритет, необходимость действия и создающим резюме в формате JSON
  1. Второй экшн — использует Formatter для парсинга JSON результата из OpenAI в отдельные переменные
  1. Третий экшн — создает новую запись в Notion с автоматическим сопоставлением всех полей: тема письма, отправитель, дата получения, содержание, категория, приоритет, флаг действия, резюме и ID письма

📑 Структура Notion базы данных

Создана специализированная таблица "Email Inbox" в Notion с полным набором полей для управления письмами.

Основное поле:

  • Тема письма — используется как основной заголовок (Title field)

Дополнительные поля:

  • От кого (Text) — имя отправителя
  • Дата получения (Date) — отслеживание времени получения
  • Содержание (Text) — полный текст письма
  • Категория (Select) — опции: Work, Personal, Sales, Support, Spam, Other
  • Приоритет (Select) — опции: High, Medium, Low
  • Действие требуется (Checkbox) — флаг требуемого ответа
  • Краткое резюме (Text) — AI-генерированное краткое описание
  • Email ID (Text) — уникальный идентификатор письма

Безопасность: Интеграция Notion настроена через Custom Integration с выделением доступа только к требуемой базе данных.

⚡ Расширения и дополнительные функции

  • Сохранение вложений — автоматическое сохранение в Google Drive с созданием ссылок в Notion записи для быстрого доступа
  • Уведомления — настроены для писем с высоким приоритетом через Slack, email и Telegram бота для мгновенного оповещения критичных писем
  • Продвинутые фильтры — исключают noreply письма, спам и позволяют обрабатывать только письма от указанных отправителей
  • Условные автоответы — автоматически отправляются для категорий Sales и Support с использованием Zapier шаблонов ответов, экономя время на рутинные ответы

💰 Оптимизация и экономия средств

Стратегии снижения стоимости:

  • Выбор модели — использование GPT-3.5-turbo вместо дорогого GPT-4

  • Few-shot примеры — в промпте улучшают качество анализа AI
  • Кэширование — результаты в промежуточном хранилище Zapier предотвращают переобработку писем при сбоях
  • Батчинг и расписание — оптимизируют использование API квот

ClickUp Reports Agent

📋 Краткая сводка

Полностью готовый к использованию Python-агент для автоматизированной оценки качества выполнения задач в ClickUp. Система загружает задачи, анализирует их через локальную AI-модель, выставляет оценки по критериям скорости и качества, а затем автоматически записывает результаты обратно в ClickUp с полной историей анализа.

Суть проекта

ClickUp Reports Agent — реализованный инструмент для объективной оценки качества выполнения задач. Агент:

  • Загружает активные задачи из ClickUp по выбранному пространству или списку
  • Формирует структурированный промпт с полной информацией о задаче (описание, история комментариев, чеклисты, контекст проекта)
  • Отправляет контекст в локально запущенную модель LM Studio (openai/gpt-oss-20b)
  • Анализирует работу и выдаёт оценки по двум критериям: скорость выполнения и качество кода/работы
  • Автоматически записывает результаты в кастомные поля ClickUp и добавляет аналитический комментарий
  • Переводит задачу в финальный статус при необходимости

Особенности реализации

Проект реализует постоянное сохранение истории оценок с возможностью проверки предыдущих результатов. Агент анализирует динамику оценок для отслеживания тренда улучшения или снижения качества, выявляя паттерны и повышая точность оценок через накопленные данные.

Система ведёт полный архив всех оценок и сравнивает текущие результаты с историческими данными для выявления закономерностей.

Готовность к использованию

Система полностью готова к использованию:

  • Поддерживает ручной запуск или запуск по расписанию (cron, GitHub Actions)
  • Режим -dry-run для безопасного тестирования конфигурации
  • Гибкая система настройки через .env файл со всеми необходимыми переменными
  • CLI-флаги для переопределения параметров на лету

Технический стек

  • Python 3.10+ с асинхронной обработкой через asyncio
  • ClickUp API — чтение и запись задач, работа с кастомными полями
  • LM Studio с локальной моделью openai/gpt-oss-20b
  • Модульная архитектура: отдельные модули для конфигурации, API ClickUp, взаимодействия с LM Studio, основной бизнес-логики оркестратора
  • Система логирования и хранение истории оценок для отчётности

Результат проекта

Руководители и PM получают единообразные, воспроизводимые оценки всех задач без ручной проверки, экономя часы времени на анализ качества работы.

Подход к оценке становится прозрачным и объективным благодаря единой модели, которая применяет одинаковые стандарты ко всем задачам.

Система готова к интеграции с кроном для автоматического запуска и масштабируется под любые объёмы работ, обеспечивая полную готовность данных для отчётности и аналитики.

Construction AI Agent

📌 Краткая сводка

Construction AI Agent — универсальный инструмент для строительных специалистов, объединяющий поиск цен на материалы, управление Google Sheets и проверку смет. Система включает интеллектуальный поиск с кэшированием, автоматический fallback на локальную LLM, веб-интерфейс и полный мониторинг через Prometheus.

🎯 Суть проекта

Construction AI Agent реализует комплексное решение для специалистов по строительству:

Поиск материалов — интеллектуальный поиск цен с использованием OpenAI, веб-поиска и локальной базы данных (data/local_materials.csv)

Управление Google Sheets — чтение, запись, генерация формул и Markdown-отчётов через естественный язык

Проверка смет — автоматическое выявление дубликатов, отсутствующих кодов и генерация подсказок

Импорт/экспорт — конвертация Excel/Google Sheets смет в формат VIORA BUILD с авто-распознаванием колонок

Управление базой — поиск записей, подготовка вставок, обновлений и удалений с подтверждением

⚡ Ключевые особенности

Агрессивное кэширование — SQLite-кэш с детерминированными ключами, сохраняется после перезапуска, экономит API-бюджет при повторных запросах

Надёжный fallback — автоматический переход на локальную LLM (LM Studio, qwen/qwen3-vl-4b) при недоступности OpenAI API

Оптимизация производительности — ограничение скорости запросов и поддержка параллельных потоков при пакетном поиске материалов

🔌 Интеграции и возможности

Google Sheets — полная интеграция через сервисный аккаунт, синхронизация базы материалов между облаком и локальным CSV, импорт/экспорт смет

Веб-интерфейс — Flask + Vue/Tailwind (frontend/unified.html) с удобным UI для всех операций

Программный доступ — класс ConstructionAIAgent для интеграции в различные рабочие процессы через CLI и код

Расширенный веб-поиск — поддержка Bing Search и ChatGPT Search для актуальных цен на материалы

📊 Мониторинг и наблюдаемость

Система автоматически поднимает HTTP-эндпоинт с метриками Prometheus (порт 9000 по умолчанию) в формате text exposition.

Отслеживаемые метрики:

  • количество и время поиска материалов
  • попадания и промахи кэша цен
  • количество запросов к LLM с учётом fallback
  • число и длительность команд Google Sheets
  • число и длительность проверок смет

Интеграция — совместимо с Prometheus/Grafana для полной видимости в работу системы

🏗️ Технический стек

Язык и окружение: Python 3.10+ с асинхронными операциями

API и сервисы: OpenAI API, Google Sheets API (через сервисный аккаунт)

Хранилище: SQLite для локального кэширования

Фронтенд: Flask + Vue/Tailwind

Фреймворки: LangChain для расширенных агентских возможностей

Мониторинг: Prometheus metrics

Архитектура: модульная система с отдельными компонентами для поиска цен, работы с Google Sheets, проверки смет, импорта Excel, управления кэшем и базой материалов

Telegram to ClickUp

📋 Краткая сводка

Telegram to ClickUp — полнофункциональная система автоматической обработки голосовых сообщений из Telegram группы и создания задач в ClickUp. Система транскрибирует аудио через OpenAI Whisper, анализирует текст через GPT-4 и автоматически создает задачи с полной информацией (название, описание, дедлайн, приоритет, ответственный). Работает по расписанию (каждый час), поддерживает различные форматы аудио и интегрируется с ClickUp REST API.

🎯 Суть проекта

Разработана полнофункциональная автоматизация, которая:

  • Проверяет новые голосовые и аудио сообщения в Telegram группе каждый час
  • Транскрибирует их через OpenAI Whisper API с высокой точностью
  • Анализирует текст через GPT-4 для интеллектуального извлечения параметров задач
  • Создает отдельные задачи в ClickUp с полной информацией: названием, описанием, дедлайном, приоритетом и ответственным
  • Поддерживает различные форматы аудио: голосовые сообщения, пересланные голосовые, аудио файлы (MP3, OGG, M4A, WAV), сообщения из каналов и пересланные аудио из других чатов

✨ Ключевые возможности

Интеграция и API

Система полностью интегрирована с ClickUp REST API для прямого создания задач по токену. Поддерживает гибкую интерпретацию дедлайнов — как в формате полных дат (YYYY-MM-DD), так и в полном ISO 8601 формате (2025-01-05T12:30:00+03:00) и относительных временных фраз («завтра», «через неделю», «до пятницы»).

Управление состоянием и производительность

Система ведёт управление состояния через state.json для отслеживания последнего обработанного события Telegram и предотвращения двойной обработки сообщений. Параллельная обработка (загрузка аудио, транскрибирование, анализ через GPT) ускоряет обработку больших очередей голосовых сообщений.

⚙️ Конфигурация и гибкость

Проект предоставляет расширенную конфигурацию через config.json с управлением:

  • Сроками хранения логов и архивных файлов
  • Параметрами кэширования участников ClickUp
  • Количеством параллельных работников при загрузке и обработке через OpenAI
  • Стратегией повторных попыток при сбоях API
  • Автоматическими напоминаниями в ClickUp до дедлайна
  • Отправкой итоговой сводки в Telegram

Сопоставление исполнителей

Поддерживает ручное сопоставление исполнителей и их псевдонимов для ClickUp через assignee_map и assignee_aliases, что позволяет правильно назначать задачи по именам, упомянутым в голосовых сообщениях. Все API ключи хранятся безопасно в переменных окружения или защищённом файле.

📊 Мониторинг и отчётность

Автоматические отчеты

Система автоматически ведёт подробные Markdown-отчеты после каждого запуска в папке logs/, содержащие:

  • Количество обработанных сообщений
  • Полные транскрипции голосовых
  • Извлеченные задачи с параметрами
  • ID созданных задач в ClickUp
  • Информацию об ошибках

Уведомления и логирование

При включении send_summary_to_telegram бот отправляет краткую сводку в Telegram чат с информацией о количестве сообщений, задач, ошибок и ссылкой на детальный лог. Логирование поддерживает разные уровни детализации через переменную LOG_LEVEL, что помогает при отладке. Система управляет сроком хранения логов и архивных файлов через log_retention_days и tasks_retention_days.

🧪 Режимы работы и тестирование

Автоматизация

Проект полностью готов к использованию с автоматическим запуском по расписанию (каждый час) через системную задачу.

Режимы тестирования

  • -dry-run — безопасное тестирование конфигурации без создания задач в ClickUp
  • -limit — ограничение количества обработанных сообщений при тестировании

Повторное создание задач

Функция create_clickup_tasks.py позволяет повторно создавать задачи из сохранённых JSON файлов при необходимости, включая режимы --dry-run и --force для пересоздания уже существующих задач.

Тестирование

В репозитории есть полный набор юнит- и интеграционных тестов с моками Telegram, OpenAI и ClickUp для проверки разбора исполнителей, дедлайнов, кэширования и полного цикла обработки.

🛠️ Технический стек и архитектура

Основные технологии

  • Python 3.10+ с асинхронной обработкой через параллельные работники
  • Telegram Bot API для получения голосовых сообщений
  • OpenAI API (Whisper для транскрипции + GPT-4 для анализа)
  • ClickUp REST API для создания задач с полными параметрами
  • SQLite для локального кэширования участников ClickUp

Структура проекта

  • Модульная архитектура: отдельные модули для работы с ClickUp API, парсинга параметров задач, управления логами и состоянием
  • Управление зависимостями через pip-tools с requirements.in и requirements.lock
